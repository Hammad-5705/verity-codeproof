# Changelog

Notable project changes are recorded here.

## 0.1.0 — Initial public alpha

- Add the CodeProof CLI and Git diff collector.
- Add evidence-linked heuristics for credential-like literals, dynamic evaluation, shell-enabled subprocesses, risky pickle/YAML loading, and swallowed exceptions.
- Add opt-in pytest execution with fixed arguments and a timeout.
- Add opt-in OpenAI-compatible diff analysis, bounded input, and advisory finding labels.
- Add terminal, Markdown, JSON, and self-contained HTML reports.
- Add GitHub Actions quality matrix and pull-request report workflow.
- Add custom architecture visuals, animated explainer, demo fixture, security policy, and threat model.
