# Contributor Covenant Code of Conduct

## Our pledge

We as contributors and maintainers pledge to make participation in the VerityAgent CodeProof project a respectful experience for everyone, regardless of background, identity, experience level, or viewpoint.

## Our standards

Examples of constructive behavior include welcoming feedback, explaining technical decisions, focusing on what is best for the project, and showing empathy toward other contributors.

Unacceptable behavior includes harassment, personal attacks, discrimination, deliberate intimidation, and sharing private information without permission.

## Enforcement

Project maintainers may edit, reject, or remove contributions that violate this code of conduct and may restrict participation when needed to keep the community safe. Report concerning behavior privately to the project maintainers using the contact channel listed on the VerityAgent profile/site.

This code applies in project spaces and when an individual is representing the project in public.
